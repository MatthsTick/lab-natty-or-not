# Natty or Not: Explorando IAs Generativas 🚀🤖

## 📒 Descrição
Este projeto foi desenvolvido como parte do Lab **Natty or Not** da DIO, com o objetivo de explorar o potencial das **IAs Generativas** na criação de conteúdos realistas e criativos. A proposta é entender como essas tecnologias podem ser aplicadas de forma prática e ética, simulando resultados cada vez mais próximos do “natty”.

## 🤖 Tecnologias Utilizadas
- ChatGPT (IA Generativa para criação de textos)
- Git e GitHub
- Markdown
- Plataforma DIO

## 🧐 Processo de Criação
Inicialmente, foi realizado o fork do repositório oficial da DIO. Em seguida, utilizei uma IA Generativa para auxiliar na criação de descrições, estruturação do README e organização das ideias do projeto. Todo o conteúdo foi revisado para manter clareza, coerência e alinhamento com os objetivos do desafio.

## 🚀 Resultados
- Repositório versionado no GitHub
- README bem estruturado e documentado
- Compreensão prática sobre o uso de IAs Generativas
- Projeto pronto para compor o portfólio profissional

## 💭 Reflexão
Criar algo “natty” com IA é um desafio interessante, pois exige equilíbrio entre automação e pensamento crítico humano. A IA acelera o processo, mas a curadoria e intenção continuam sendo responsabilidades essenciais do desenvolvedor.
